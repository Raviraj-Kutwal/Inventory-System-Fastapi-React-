# 📦 Inventory System  
Basic Inventory Tracker with FastAPI & React

A simple full-stack inventory tracking application built with **FastAPI (Python)** for the backend and **React** for the frontend. This project demonstrates basic **CRUD (Create, Read, Update, Delete)** operations to manage inventory items.

---

## 🔍 Features

✔ Add new inventory items  
✔ View all products  
✔ Update item details  
✔ Delete items  
✔ FastAPI REST API  
✔ React UI for interactive UI

---

## 🧰 Tech Stack

### Backend
- FastAPI (Python)
- SQLite / SQLModel or SQLAlchemy
- REST API

### Frontend
- React.js
- Fetch / Axios for API calls
- Basic routing & UI components
